Known preview-endpoint limitation: FHIRBridge's /api/v1/transformation-rules/preview endpoint takes sampleValue as a bare object?. System.Text.Json deserializes a JSON array into that slot as a single boxed JsonElement, which is not IEnumerable — so TransformConfigExtensions.AsItems() treats the whole array as one item instead of enumerating it. ConcatenationTemplating and ArrayListOperations previews on array-shaped input silently no-op (output = input, unjoined) as a result. Rows marked computed offline below are hand-computed from the documented op semantics (join/concat with the configured separator) instead of the live engine output, to avoid showing a misleading no-op as if it were real.
