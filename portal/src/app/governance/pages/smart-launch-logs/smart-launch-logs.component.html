SMART Launch Logs

SMART on FHIR launches completing — EHR launch, standalone, and workflow launches. No Segue portal user is involved here; see Authentication Logs for that.

What am I looking at?

Every row is one attempt to connect to a source EHR via SMART on FHIR — a provider launching from inside the EHR, a standalone app sign-in, or a backend token exchange. This is about the connection to the EHR itself, not a Segue portal user logging in.

A failed row here

Usually means something on the EHR side rejected the connection — an expired or mismatched signing key, an unregistered app, or a misconfigured client ID. The Failure Reason column shows the actual rejection message from the EHR.
