SMART Launch Logs

SMART on FHIR launches completing — EHR launch, standalone, and workflow launches. No Segue portal user is involved here; see Authentication Logs for that.

What am I looking at?

Every row is one attempt to connect to a source EHR via SMART on FHIR — a provider launching from inside the EHR, a standalone app sign-in, or a backend token exchange. This is about the connection to the EHR itself, not a Segue portal user logging in.

A failed row here

Usually means something on the EHR side rejected the connection — an expired or mismatched signing key, an unregistered app, or a misconfigured client ID. The Failure Reason column shows the actual rejection message from the EHR.

Patient Context, Granted Scope, Token Cache Key

Populated for interactive (EHR-launch / standalone) sign-ins only. Patient Context shows whether Epic actually returned a patient claim on this sign-in — if a workflow's Patient search later fails with "requires demographics or _id", check this column first: No means the search never had a launched patient to scope to. Token Cache Key is a one-way hash of the session this token was saved under; compare it across rows for the same source connection to confirm a later run reused the same login session instead of a different (or missing) one.
