Authentication Logs

Login, logout, MFA, and lockout events — required HIPAA §164.312(b) evidence.

What am I looking at?

Every row is one sign-in related event — a successful login, a failed attempt, a logout, an MFA code check, a single sign-on attempt, or a lockout. This includes both portal user logins and the backend token exchanges Segue makes with EHR systems on your behalf.

Failed attempts

A failed login is normal, everyday activity (a mistyped password) — not automatically something to investigate. Repeated failures against the same account in a short time is the pattern worth watching; that's exactly what triggers an account lockout, which shows up separately in Security Events.
