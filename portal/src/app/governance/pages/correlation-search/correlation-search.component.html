Correlation Search

Paste a Correlation ID to see everything that happened during that execution, across every governance and operations table in one place.

What am I looking at?

This isn't its own log — it's a cross-reference lookup. Every screen in Operations and Governance stamps its rows with a shared Correlation ID whenever they're part of the same event. Paste that ID here and this screen pulls the matching rows from every one of those tables into a single timeline, so you don't have to check each screen separately.

Where do I get a Correlation ID?

Copy it from any row in Pipeline Executions, Scheduler History, Errors, API Requests, or most other log screens — they all have a Correlation ID column.

A "Raw" toggle on some entries shows the full underlying record — useful for deep technical troubleshooting, not needed for everyday use.
