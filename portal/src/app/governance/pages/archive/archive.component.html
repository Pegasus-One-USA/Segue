Archive

Every retention purge archives expiring rows to a durable NDJSON file before deleting them. This lists the most recent archive run per log type.

What am I looking at?

Before the retention job permanently deletes old log rows, it saves them to a durable file first. This screen shows, per log type, when that last happened and how many rows were saved — so purged data isn't truly gone, just moved out of the live database.

"Restore range…" isn't wired up yet — the archived file is retrievable at the shown location, but there's no one-click way to load it back into the live database today.
