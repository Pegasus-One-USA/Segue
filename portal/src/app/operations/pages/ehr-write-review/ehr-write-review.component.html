EHR Write-Back Review

Writes to an EHR that need a person: the outcome is unknown, the EHR refused them, or the send never finished.

What am I looking at?

An EHR files a repeated create as a second copy in the chart, so a write whose outcome is not known is never retried on its own. Check the patient's chart in the EHR, then:

  • It is in the EHR: enter the id the EHR gave it. It is recorded as written and never sent again.
  • Not in the EHR: release it. The next run of its workflow sends it once more.

A refusal caused by configuration (no API on the client id, a rate limit) is retried automatically once it is fixed, and a refused record that changes in the source is retried too. Release a refused record only when you know the same content will now be accepted.

Only ids, statuses and the EHR's outcome codes are shown, never clinical content.
