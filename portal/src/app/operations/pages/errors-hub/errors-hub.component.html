Errors

Every row is one problem that happened somewhere in Segue — while running a workflow, dispatching a schedule, or handling a webhook. Routine, expected outcomes (a wrong password, a duplicate name) are handled elsewhere and never show up here — everything on this screen is a genuine, unexpected failure.

What to do — shown in the "What to do" column

Check your configuration
Something in your own environment likely needs attention — an expired connection, an unreachable destination, a bad mapping. Worth investigating yourself first.
Contact support
Not something you can fix from here. Click the row, use "Copy for support", and send the reference ID to your support team.

Click a row to see the full technical detail (exception type, message, stack trace) — collapsed by default to keep the list readable. The Correlation ID links to Correlation Search, showing everything else that happened around the same event.

Problems that happened while running your workflows or connecting to Segue. Use the Overview to see what is happening and share a report; use All errors to search, filter and resolve individual errors.
