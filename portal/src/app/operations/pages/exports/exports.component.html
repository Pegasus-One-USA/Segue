Exports

Every destination write ("export") completing — CSV, SQL, S3, SFTP, and every other destination type.

What am I looking at?

Every row is one destination write finishing — a CSV file generated, a SQL table updated, an SFTP upload completed. Think of it as a delivery receipt: did the data actually land where it was supposed to go.

Reading the Status column

Succeeded means the write completed and records landed. NoData means the write ran but there was nothing to write — usually normal (no new/changed records that cycle), not a failure.

Row count and file size are shown per export, so you can spot an unexpectedly empty or unusually small delivery at a glance.
