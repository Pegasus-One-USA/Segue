API Requests

Every outbound call to a source/destination/terminology endpoint — method, URL, status, and duration. Click a failed status to see why it failed.

What am I looking at?

Every row is one outbound call FHIRBridge made to one of your own configured connections — an EHR source (like Epic), a destination, or a terminology service. Only the method, URL, status, and how long it took are recorded — never the actual health data being moved.

Reading the Status column

2xx means the call succeeded. Anything else — a timeout, a connection refusal, an authentication rejection — usually means the endpoint you configured isn't reachable or your credentials need attention. Click a failed status to see the specific reason.

A slow or frequently-failing endpoint here is a good early signal to check that connection's health before it shows up as a bigger problem in Pipeline Executions.
