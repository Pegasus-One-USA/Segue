Pipeline Executions

History of data-sync runs. Each row is one run of a configured job that moves records from an input to a target. Click a row to see the breakdown by data type (Patients, Observations, …).

What am I looking at?

Every row is one execution of a configured pipeline route — a saved rule that reads records from an input (Epic, Healow, a FHIR server, a file…) and writes them to a target (a database, CSV, SFTP…).

How a run gets here — shown in the Triggered By column

Scheduled
Ran automatically on its schedule — unattended, system-to-system inputs.
Webhook
Started because an external system pushed data in.
Manual / Bulk
Started by an admin, or a large bulk export.
Interactive launch
A user launched the app from the EHR (e.g. epic-ehr-launch); the resulting sync lands here too.

What the numbers mean

Read records pulled from the input
Written records delivered to the target
Run Errors failures recorded for this run

Statuses

Completed all good Completed with errors some records failed Failed nothing written Skipped dependencies disabled Running in progress

This is the config-driven engine. Visual "Run"-button and workflow-graph launches instead appear under Execution History.
