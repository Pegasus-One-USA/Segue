FHIR Bulk Export Workflow Overview The FHIR Bulk Export Service is intended to fulfill the bulk data export requirements as of the HTI-1 Final Rule. This feature leverages FHIR R4 APIs certified under the 21st Century Cures & HTI-1 CEHRT (g)(10) criterion. The FHIR Bulk Export service enables API consumers to make asynchronous requests to export USCDI (United States Core Data for Interoperability) clinical data for all patients in a particular athena context. With FHIR Bulk Export, you can retrieve data for multiple patients or resources at a time. Potential use cases to consider for the FHIR Bulk Export service are: One-time initial load of data for seeding another system, such as a data warehouse Monthly data capture synchronizations (using the \_since parameter to limit the amount of data returned) Monthly export of a few specific resources (using \_type parameter) Population health data transfer We do not recommend using FHIR Bulk Export for real-time access needs, daily data synchronizations, or scenarios when a single patient’s health information needs to be obtained. We recommend using Data View for daily data synchronizations, especially when data is sourced from multiple Practices.
