Configuration & Pipeline 8 tables

The tenant-owned configuration chain a customer builds in the workflow designer: a source and a destination are joined by a mapping profile, wrapped in a route (the workflow). Deleting a tenant cascades to all of these; mapping→source and route→mapping use Restrict so you can't orphan a run.

Generated from FHIRBridgeDbContextModelSnapshot.cs (EF Core 9.0.10, SQL Server) — 18 DbSets plus the owned MappingFields child table. Embedded value objects (SourceAuthenticationConfiguration, SourceInteractiveConfiguration, SecretReference) are stored as extra columns on their parent table, not as separate tables. Every configuration table carries CreatedOnUtc / ModifiedOnUtc / DeletedBy / IsDeleted / IsEnabled / RowVersion; a global query filter hides soft-deleted rows.
