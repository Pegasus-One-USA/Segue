Infrastructure Cost Planning

Azure Hosting — Pricing Options

Five deployment configurations for the Segue platform, from a fully managed minimum footprint through a large managed tier, plus single-VM alternatives on Linux and Windows. Each option is priced independently so it can be compared on its own terms.

Prepared for: Segue Client Deployment Region basis: Azure Pay-As-You-Go, East US Prepared: September 2026
All prices on this page are estimates for budgeting purposes — confirm exact rates in the Azure Pricing Calculator before committing spend.

Single VM — Linux Lowest Cost

All four components — app, worker, Postgres, Redis — run as Docker containers on one Linux VM, using the project's existing local Terraform topology instead of separate PaaS services.

$164/mo
$1,968 / year
ComponentSizeMonthly
Virtual MachineStandard_D4s_v3 — 4 vCPU / 16 GiB, Ubuntu Linux$140.16
Managed diskPremium SSD, 128 GB$19.71
NetworkingStatic public IP + light bandwidth$3.65
The cheapest way to run the full stack, because one VM's compute is shared across all four containers instead of billed per-service. Trade-off: no independent scaling per component, one host to patch and reboot, and no managed-service SLA — a restart or VM-level failure takes everything down at once.

Single VM — Windows

The same all-in-one layout as Option 4, on a Windows Server guest instead of Linux.

$231/mo
$2,772 / year
ComponentSizeMonthly
Virtual MachineStandard_D4s_v3 — 4 vCPU / 16 GiB, base compute$140.16
Windows Server licenseIncluded guest OS licensing surcharge$67.16
Managed diskPremium SSD, 128 GB$19.71
NetworkingStatic public IP + light bandwidth$3.65
Same hardware, ~40% more expensive than Option 4 purely for the Windows license. It also does not run the stack natively: Postgres and Redis ship no official Windows container images, so both would need to run inside WSL2 on the VM rather than as native Windows containers — losing parity with every other environment in this project. Included here only because it was directly evaluated against the Linux option, not as a recommendation.

Basis for these figures: Azure Pay-As-You-Go list pricing, East US region, September 2026. Container Apps priced on the Consumption plan at $0.0864/vCPU-hour and $0.0108/GiB-hour, running continuously (730 hours/month). All figures are planning estimates rounded to the nearest dollar — they exclude egress bandwidth beyond the light allowance noted, Azure Support plans, reserved-instance or savings-plan discounts, and sales tax.

Before committing budget to any option, confirm current rates in the Azure Pricing Calculator for the exact SKUs and region the deployment will use — Azure pricing changes periodically and regional rates vary.
