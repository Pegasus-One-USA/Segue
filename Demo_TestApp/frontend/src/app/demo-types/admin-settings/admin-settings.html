New 11 Feature Flag

Patient_Standalone (Role: Patient)

athenahealth (vendor toggle on the Patient Standalone screen)

A separate workflow/base URL for testing the athenahealth Patient Standalone flow instead of Epic/MyChart — used only for the connect/list step (no detail or CSV export). The workflow's source node must be an athenahealth Patient-audience connection, opted into public launch. athenahealth's sandbox has one fixed FHIR base URL (no per-hospital directory), so instead of a picker, paste the id of a pre-seeded EhrEndpoint row (type MyChart) whose FHIR base URL is the athenahealth sandbox — FHIRBridge's public-patient-standalone-url endpoint requires one to mint against.

eClinicalWorks / eCW (vendor toggle on the Patient Standalone screen)

A separate workflow/base URL for testing the eCW Patient Standalone flow instead of Epic/MyChart or athenahealth — used only for the connect/list step (no detail or CSV export). The workflow's source node must be a Healow (eCW) Patient-audience connection, opted into public launch. eCW's Patient audience currently targets one fixed practice (no per-hospital directory), so instead of a picker, paste the id of a pre-seeded EhrEndpoint row (type MyChart) whose FHIR base URL is that eCW practice's endpoint — FHIRBridge's public-patient-standalone-url endpoint requires one to mint against.

Provider_Standalone (Role: ProviderStandalone)

Provider_InApp (Role: ProviderInApp)

Uses the Provider Standalone Base URL above for its FHIRBridge connection. Must be a workflow opted into public launch via POST /api/v1/workflows/{{ '{' }}id{{ '}' }}/enable-public-launch.

eClinicalWorks / eCW (Provider EMR)

A separate EHR-launch workflow for the eCW Provider EMR launch instead of Epic. Its source node must be a Healow (eCW) Provider EHR-launch connection, opted into public launch. Both share the one registered Launch URL — when a launch arrives, the app auto-selects this workflow if the launching EHR's iss is an eCW practice (host *.ecwcloud.com); otherwise it uses the Epic/default one above. Leave blank to keep eCW Provider EMR off.

Backend_System (Role: BackendSystem)

The workflow run (FHIRBridge /run) behind the Practitioners view's Import Practitioner button. The submitted practitioner ids are passed as its search criteria. Uses the Provider Standalone Base URL above for its FHIRBridge connection.
